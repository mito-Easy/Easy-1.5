# マスター自作言語・ゲームエディタ 🚀

Tkinterで作られた、独自の日本語・英語スクリプトを入力してその場で実行できる、軽量な自作言語インタプリタ環境（統合エディタ）です。  
最新バージョンでは、高度な**条件分岐（if構文）**に加え、ゲーム制作に特化した**HPゲージや得点システム、BGM再生機能**を搭載しました！

---

## ✨ 今回追加・強化された主な機能

### 1. 🔀 高度な条件分岐（if-elif-else）
自作言語内で数値や変数の比較ができるようになりました。ネスト（入れ子構造）の追跡スタックを搭載しているため、条件を満たしていないブロックの処理は正しくスキップされます。
- `==`（等しい）、`!=`（等しくない）、`>`、`<`、`>=`、`<=` のすべての比較演算子に対応。

### 2. 🎮 リアルタイム・ゲームUI
アプリの上部に、ゲームのステータスを視覚的に表示するヘッダーパネルを新設しました。
- **HPゲージ**: 0〜100% の残量を表すプログレスバー。
- **SCORE表示**: リアルタイムで変動する得点ラベル。

### 3. 🎵 BGM（バックグラウンドミュージック）再生
Windowsの標準機能を利用し、裏で音楽をループ再生・停止するコマンドを追加しました。
- 別スレッド（非同期）で再生されるため、音楽が流れている間もスクリプトの実行や文字のアニメーションが止まりません。

---

## 📜 自作言語のコマンドリファレンス

最新版で使える主要なコマンドの一覧です（日本語・英語の両方に対応）。

| コマンド (日本語) | Command (English) | 使い方・例 | 説明 |
| :--- | :--- | :--- | :--- |
| **もし** | `if` | `もし 桁 == 0` | 条件分岐の開始（要：終わり/endif） |
| **それとも** | `elif` | `それとも 桁 < 4` | 別の条件を指定する |
| **その他** | `else` | `その他` | すべての条件を満たさない場合 |
| **終わり** | `endif` | `終わり` | 条件分岐ブロックの終了を宣言 |
| **HP** | `hp` | `HP 40` / `HP 変数名` | HPゲージの残量を 0〜100% で変更 |
| **得点** | `score` | `得点 100` / `得点 変数名` | SCORE表示を瞬時に書き換える |
| **音楽** | `bgm` | `音楽 battle.wav` | 指定した `.wav` ファイルをループ再生 |
| **音楽停止** | `bgm_stop` | `音楽停止` | 再生中のBGMを完全にストップする |
| **計算** | `calc` | `計算 答え = 桁 + 5` | 変数を使った四則演算（`+`, `-`, `*`, `/`） |
| **カラー** | `color` | `カラー 赤` / `カラー 黒` | 出力画面の背景色と文字色を瞬時に変更 |
| **バイブ** | `vibe` | `バイブ 3` | 画面を赤くチカチカさせて振動を表現 |

```text
カラー 赤

待つ 1.5

カラー 緑

得点 得点
HP 100
音楽停止

警告 ゲームクリア！
```

## 🛠️ インストールと実行方法

1. このリポジトリをクローンまたはダウンロードします。
2. フォルダを開き、以下のコマンドでアプリを起動します：
   ```bash
   python main.py
   ```
3. Windows環境でBGM再生をテストする場合は、同じフォルダに `.wav` 形式の音声ファイルを配置してください。
